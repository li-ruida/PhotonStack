# Documentation Guide

This folder contains the public documentation for PhotonStack.

## Start Here

- [`build.md`](build.md): environment setup, build, packaging, and local development
- [`features.md`](features.md): current capabilities overview
- [`cli.md`](cli.md): CLI scope and design notes
- [`image-pipeline.md`](image-pipeline.md): processing pipeline overview
- [`architecture.md`](architecture.md): repository architecture and shared-engine structure
- [`compliance/third-party-dependencies.md`](compliance/third-party-dependencies.md): tracked runtime and build dependencies

## Suggested Reading Order

If you are new to the repository:

1. Read [`features.md`](features.md) for the product surface.
2. Read [`build.md`](build.md) for setup and build steps.
3. Read [`cli.md`](cli.md) and [`image-pipeline.md`](image-pipeline.md) for workflow details.
4. Read [`architecture.md`](architecture.md) if you want implementation structure.

## Notes

- The repository is macOS-first.
- `README.md` in the repository root is intentionally short.
- This guide is the main entry point for deeper project documentation.
