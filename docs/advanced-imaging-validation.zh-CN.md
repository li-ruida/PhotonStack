# 高级深空处理验收记录

基线是 0.1.5（d2dd227）。以下记录本地开发结果。对照范围见[能力调研](capability-comparison-2026-11-17.zh-CN.md)。

## 双窄带第一阶段

App 入口在后期调整 → 高级 → 双窄带与 HOO。可处理单张选中原片、选多张 FITS 进行共同星点配准与 Sigma 堆栈，或选取已在同一像素网格上的 Hα、OⅢ 单色母片调整 HOO 的绿色通道。命令行使用相同引擎：

```sh
photonstack narrowband-extract --input light.fit --output-dir extracted
photonstack narrowband-stack --output-dir stacked light1.fit light2.fit light3.fit
photonstack narrowband-compose --ha stacked/Ha.fits --oiii stacked/OIII.fits --green-ha 0.25 --output-dir mixed
```

每个完整的 2×2 拜耳格给出一个红像素样本作为 Hα 估计，另三个绿、蓝像素的均值作为 OⅢ 估计。按 FITS 存储顺序读取，应用 BZERO、BSCALE 及拜耳相位偏移，保留有符号线性数值，不对颜色作显示拉伸。奇数边长的末行或末列不构成完整格时舍弃。两条通带的估计取决于滤镜与相机响应，当前不做串扰反演、绝对测光或亚像素通带质心校正。多帧选择须是同一目标、同一通带组合；传感器母片校准入口见下文；当前没有自动校准库匹配或质量筛选入口。合色要求两张母片已配准，仅检查相同尺寸无法证明是同一天区。

### 已运行

- 全部四种拜耳排列及整数相位偏移，输入含负数、奇数边界和 NaN。测试从 FITS 数据段独立读取输出，校验逐像素物理值。错误拜耳和已有目的地均拒绝写入。
- 人工星场三帧、已知平移：共同配准后对全覆盖内区逐像素比较 Hα 和 OⅢ，与真值的绝对差均不超过 0.15 个样本单位。合色对照独立公式 R=H、G=0.25H+0.75O、B=O。
- 真实 2160×3840 GRBG 面纱原片：每张输出 1080×1920；独立逐像素读取对比，Hα 最大绝对差 0，OⅢ 最大绝对差约 0.001303 个原始计数（浮点舍入）。单次约 0.02 秒、峰值 RSS 约 23 MiB。

- 复验入口：`ctest --test-dir build/release -R photonstack_narrowband_extraction --output-on-failure`。此组包括提取、堆栈与合色的 CLI 集成测试。

## 已解算 FITS 天区拼接

在天区拼接工作流中导入两张或更多已解算的 FITS 母片，在「处理 → 配准」选择「天球坐标」，然后预览或生成成片。预览会标出用于复核的共同星点；质量报告的残差按第一张母片的全分辨率像素计量。没有足够共同星点时，坐标仍可定位，但报告明确提示未复核。星点充足而相对位置明显不符时中止，建议检查解算或改用星点配准。单张母片也可重投影到无畸变的 TAN 画布。

```sh
photonstack mosaic --alignment wcs --blend feather --output veil.fits east.fit west.fit
```

- 支持 ICRS 的 RA/DEC TAN、2–5 阶正向 TAN-SIP 畸变、CD 或 PC/CDELT 像素矩阵。视场投到共同的切平面，重算输出 FITS 的参考像素和像素尺度；不把原始畸变头复制到成片。原片目录当前流程新堆的母片若没有解算，仍应使用星点自动配准。App 此模式本身不做盲解或在线星表校准。
- 两张 2160 × 3840 的面纱实拍母片生成 3951 × 3880 的线性拼接。独立测试 App 已手动选择 WCS 预览并生成全分辨率成片，报告 242 对共同星点，残差中位 0.47、P95 0.99 像素。CLI 羽化、关闭曝光匹配的单次 release 运行约 0.91 秒，峰值 RSS 约 617 MiB；不含后续 TIFF 显影。
- 用 Astropy 6.0.1（WCSLIB）独立打开原片与 App 写出的 FITS，每个 55 像素格挑取亮源再测量星心。两块天区各自单独覆盖区的 1582 和 1595 个亮源，中位偏差约 0.018 和 0.019 像素，P95 均小于 0.05。重叠区分别取到 370 和 334 个候选源，从原片预计位置到**成片**星心偏差的 P95 为 0.41 和 0.53 像素。两张**原片彼此**的 P95 为 0.75 和 0.77 像素。两组重叠候选可能含同一颗星，数量不能相加当作独立样本；这些是相对几何误差，不是对 Gaia 绝对坐标的测量。
- `photonstack_wcs_mosaic` CLI 测试覆盖跨赤经 0°、旋转、缩放、SIP 畸变和已知线性亮度坡面。完整及半宽预览均核对输出尺寸、参考像素、覆盖率与科学像素值。坐标对照由 [Astropy 脚本](../tools/scripts/qa/wcs_mosaic_golden.py) 独立生成，常规测试无 Python 第三方依赖。无效头、背面投影及与星场不符的坐标应被拒绝。[实拍复核脚本](../tools/scripts/qa/veil_wcs_residuals.py) 可传入两张母片和输出 FITS 重跑。
- 外部绝对坐标抽查：[Gaia DR3 星表](https://doi.org/10.17876/gaia/dr.3/1)，在画布 10%、50%、90% 宽高的九个交点各查询半径 0.12°、G 星等 10–14 的恒星。根据恒星自行，把 2016.0 星表位置推算到观测日 2026-09-09。在 390 个候选中排除缺少自行、相距不足 8 像素或局部信噪不足的目标；312 个实际测得星心的绝对偏差中位 **0.385 像素**，P95 **1.659 像素**。中心区 35 颗为 0.247 / 0.614 像素；右下区中位 1.546，上部中央区 P95 达 2.261。拼接不对输入已有解算作星表再拟合，也不能据此声称全画幅亚像素绝对精度。[复验脚本](../tools/scripts/qa/catalog_wcs_residuals.py) 缓存原始星表响应以便离线复验。
- 回归：54 项 CTest 通过；指定真实 CLI，串行运行 Swift release 测试，三个目标分别通过 424、66 和 69 项。

## 显影后星云与恒星分层

后期调整 → 高级 → 星云与恒星分层。输入为显影后的 TIFF，可导入同尺寸、同位置的无星 TIFF，或配置本机外部去星程序。程序与模型单独安装，App 不包含去星模型。外部程序直接接收参数，在独立临时目录运行；取消或无效输出不会覆盖原图。

分层文件夹保存线性浮点 `starless.fits`、包含负残差的 `stars.fits` 和来源摘要。分别调整星云曝光、拉伸、饱和度及恒星曝光、饱和度后，每次应用保存新的 TIFF、FITS 与配方。选择“打开分层”可恢复设置；修改过的基础图层会被拒绝重组。TIFF 超出显示范围的值会截断，FITS 保留原值。此入口不等同于未拉伸线性母片的去星，星层也可能包含外部算法对背景的残差。

- CLI 测试独立读取 TIFF/FITS 数据，验证负残差保留、默认重组、恒星降低一档的数值关系、尺寸不匹配、无效参数与已有输出保护。
- Swift 集成测试使用真实 CLI 验证分层、保存及重开配方、重复渲染结果一致、工作区导出、源文件不变和基础图层修改检测。外部工具测试覆盖带空格的路径、无效输出、取消和临时文件回收。
- 回归：55 项 CTest 和 563 项 Swift 测试通过（425、69、69）。

## 可检查的多项式背景校正

App 增加“背景采样与模型”窗口，可在原图添加、选择、禁用、移动或删除采样点，查看原图 / 校正 / 模型 / 扣除量，检查逐通道采用情况及拟合残差。参数变化会使旧预览失效；保存时新建目录，并把校正 FITS 作为主画布的可继续处理图像。配方包含源图摘要，重开时拒绝已改变的原图。详见[使用说明](background-review.md)。

- 独立合成数据：已知线性渐变加星云结构、负数及部分透明边缘。校正后的星云信号与真值最大差小于 0.0001；背景模型与真值、实际扣除量与输入输出差逐像素一致。验证了异常采样点的逐通道剔除、禁用、边缘、覆盖不足、退化几何、无效采样、源图变化和已有输出保护。零强度输出保持已覆盖像素，差图为零；零残差的显示预览对应中灰。
- 人工采样要求整个框有效，避免透明边缘留下不对称像素导致局部中值偏移。原有自动背景接口的采样行为保留。
- 面纱 3951×3880 的线性拼接：60 个人工选择的背景点，全部参与拟合。二阶、0.35 强度、本机 release 单次 1.40 秒，峰值 RSS 1037238272 字节。M31 2160×3840 母片：40 个点，其中 38 个全通道采用、2 个部分采用，单次 0.69 秒，峰值 RSS 572751872 字节。耗时包含解码、拟合、三张全尺寸 FITS 和四张缩略 TIFF 的写出，不是纯拟合或竞品速度对比。
- NumPy / Astropy 独立读取两组原图和输出：局部采样中值差为 0；校正公式的最大绝对差分别为 0.001963 和 0.001921 个输入计数，符合 Float32 舍入；覆盖率完全一致；保存的差图等于输入减输出。面纱中心、四角及边中点的 WCS 差为 0 度。M31 输入不含可识别的解算，没有标为已保留坐标。
- 在上述原图副本上加入独立已知的平面渐变，使用相同人工点重算。面纱三个通道模型恢复 RMS 占注入基准幅度的 0.0292%、0.0167%、0.6211%；M31 为 0.1274%、0.0837%、1.4967%。每通道均小于 2% 验收阈值。原图 SHA-256 不变。这个实验检验附加渐变的恢复，不证明真实星系光晕或星云背景的绝对准确性。
- 实际隔离测试 App：从线性 FITS 打开窗口，点击添加第 97 个点再删除回 96，打开 60 点配方，更新预览，切换模型和扣除量，保存后主画布转到 corrected.fits。App 写出的科学 FITS 与同配方 CLI 输出逐字节一致，独立像素复核通过。过程中发现并修复删除选中点时旧字段绑定越界，增加固定 ID 绑定回归。
- 回归：56 项 CTest、566 项 Swift release 测试通过；此后对中灰显示及预览失效状态的收尾修改单独复验对应 CLI 和 Swift 集成测试。此为当阶段本地验证记录。

## 双窄带配方与覆盖产品（0.1.5）

- 提取输出两条通带各自的有效性图；堆栈输出 Hα/OⅢ 的 Sigma 剔除后采用权重及剔除前几何覆盖率。权重为有效覆盖权重之和，重采样边缘可以是小数。堆栈仍仅使用两条通带都有效的像素格，没有把共同有效掩膜宣称为独立通带缺失数据处理。
- 每次运行保存输入、产品的 SHA-256 和合色配方。`narrowband-inspect --recipe result/recipe.txt` 检查来源与产品；`narrowband-replay --recipe result/recipe.txt --output-dir new-result` 从来源重新运行。合色配方可附加 `--green-ha` 改变绿色混合比例。输出目录必须是新目录，App 的原子发布也拒绝替换已有结果。
- App 可打开结果目录、查看线性母片及权重、重配 HOO、另存并重新运行配方。合色的无效像素输出透明掩膜与单独有效性图，不再把缺失通带当成黑色信号。
- 合成测试覆盖全部拜耳排列、相位偏移、负值、NaN、已知平移、逐通道权重、串行与多线程一致性、配方重跑、输入/结果篡改检测及已有目录保护。Swift 集成测试通过真实 CLI 提取、合色、重开和重跑。
- 同一组 144 张面纱原片，上一版与当前版依次运行耗时 14.59 / 15.38 秒，峰值 RSS 421068800 / 446119936 字节；增加摘要校验、配方和权重文件后，Ha、OIII、HOO 三张科学 FITS 仍逐字节一致。包含全部读写，未清理系统文件缓存，属于单次回归观察，不是通用性能基准。
- 隔离 App 实际提取真实原片、在主画布查看 Hα/OⅢ 并另存 HOO；保存后主画布正确切换到对应 FITS。

## 双窄带传感器校准

[操作与配方说明](narrowband-calibration.md)。在原始传感器位置完成偏置/暗场扣除和四拜耳相位分别归一化的平场校正，再提取 Hα/OⅢ。明确要求暗场、平场的偏置状态；保持负值、无效样本和来源摘要。没有暗场缩放、暗平场构建、温度匹配或校准库自动选择。元数据不足时由用户确认兼容性，不能把尺寸一致当成完整采集条件一致。

- 64 组拜耳排列/偏移/母片状态组合，独立已知的信号、偏置、暗电流、逐相位平场与渐晕，恢复的负信号和通带数值与真值一致。覆盖母片 NaN、零平场、无有效相位、元数据不匹配、缺失偏置状态、重复来源及母片篡改。三张已知抖动的人工星场，在原片加入已知偏置与渐晕后，校准堆栈的六个科学产品与未受污染的参考输出逐字节一致。
- 面纱实拍前三张 2160×3840 原片保持只读。在副本上注入合成偏置、暗电流和不同拜耳响应的渐晕，使用独立 NumPy/Astropy 复验恢复值。这不是用实际拍摄的校准母片评估噪声收益。单张 Hα/OⅢ 最大绝对差分别为 0.0078125 / 0.00390625 个原始计数，RMS 为 0.0000751 / 0.0000497。
- 堆栈后 Hα/OⅢ 最大绝对差为 0.095703 / 0.144531 个计数，均出现在亮星附近；全图 RMS 为 0.000216 / 0.000206，最大逐像素相对误差为 0.00314% / 0.00237%。合成副本写入 Float32 会先量化亮星，再参与配准，因此此实验不要求逐字节相等。最初的全图固定 0.1 计数上限在 OⅢ 亮星处超出；复核采用权重无任何变化后，采用同时限制相对误差小于 0.01% 和 RMS 小于 0.001 计数的检查，覆盖率差另外限制在 0.000001 内。实际覆盖率最大差为 5.96×10⁻⁸。原片摘要不变。
- 本机 release 三帧堆栈一次观察：无校准 0.37 秒、RSS 188301312 字节；带三张母片的校准 0.60 秒、RSS 321110016 字节。单张校准提取约 0.23 秒。包含读取、摘要、配准、诊断产品与写出，未清理文件缓存；不能用于竞品速度排名。[注入与复核脚本](../tools/scripts/qa/narrowband_calibration_validation.py) 要求 NumPy/Astropy，并只向新目录写入。
- 隔离 App 打开已保存校准配方，恢复三张母片及含偏置/已去偏置状态，选择原始副本完成提取，再从文件选择器多选三张副本完成校准堆栈。主画布正确显示 HOO；六个 GUI 科学产品与同参数 CLI 逐字节一致。文件选择器明确配置文件/目录及多选行为；不足三张在选择输出目录之前提示。

### Siril 单帧通带对照

本机 Siril 1.4.2，使用实拍首张原片的副本，运行 `extract_HaOIII -resample=oiii`；输出同为 1080×1920。虽然脚本设置 `set32bits`，本次 Siril 的两张提取产品实际为 16 位整数，比较使用 FITS 的物理计数，不假称两边都是浮点输出。Siril 的 OⅢ 包含绿色/蓝色处理、红位置插值与降采样；PhotonStack 此阶段使用完整 2×2 格内三个非红样本的均值。[Siril 算法与重采样说明](https://siril.readthedocs.io/en/stable/processing/extraction.html)

- Hα 全图物理值完全一致。OⅢ 全图 RMS 差为 71.030 计数，不能宣称两种提取等价。
- 以共同 Hα 生成掩膜：排除紧凑峰邻域后的低亮度 405502 个像素，两边 OⅢ 中位分别为 1171.667 / 1172.000，逐像素差中位为 1.667。1869 个弥散结构候选像素的差中位为 −8.000、RMS 为 95.815。候选掩膜不是经人工核准的纯面纱细丝分割，暂不据此判定细丝保真优劣。
- 1349 个未饱和候选星，用相同半径 4 像素孔径、6–9 像素背景环测量：Siril/PhotonStack 的 OⅢ 背景扣除通量比中位 0.88045，10–90 分位 0.84540–0.93401；二阶矩宽度比中位 1.00370。质心差中位为 (−0.08663, +0.08524) 像素，距离 P95 为 0.17294。[复验脚本](../tools/scripts/qa/narrowband_siril_comparison.py) 保留输入摘要及每个候选星的测量值。
- 该对照暴露了采样位置、强度及插值的区别；尚未完成整组序列的独立堆栈对照、跨通带空间质心校正和已确认细丝区域的质量验收，不能将此阶段记为双窄带能力全部完成。
