# 逐帧传感器校准与任务恢复

`calibration-run` 按明确的逐帧母片分配执行偏置、暗场和平场校准，保留线性 CFA / 单色传感器网格。每张亮场分别核对相机实体、读出、增益、binning、传感器区域、温度、曝光及平场滤镜/光路；[分组审查](calibration-library.md)中的候选不会未经选择自动变成校准参数。

当前提供 CLI 和 App 处理服务支持。**App 中的逐帧分配、执行及恢复界面尚未接通，也未替换一键成片的已有手工校准路径。** 任务完成表示所选公式已执行并保存，不等于真实相机的校准质量合格。

## 明确分配母片

```text
PhotonStack-CalibrationJob-1
temperature-tolerance 1
memory-mib 512
tile-pixels 65536
threads 4
master bias1 bias "/absolute/master-bias.fits" - included
master dark60 dark "/absolute/master-dark-60s.fits" - included
master flatHa flat "/absolute/master-flat-Ha.fits" - removed
light "/absolute/night1/Ha-001.fits" - bias1 dark60 flatHa
light "/absolute/night2/Ha-002.fits" - bias1 dark60 flatHa
```

`master` 后依次是 ID、角色、绝对路径、SHA-256、偏置状态。角色为 `bias` / `dark` / `flat`；ID 为最多 64 字符的字母、数字、下划线和连字符。偏置母片只能为 `included`，其他母片必须明确 `included` 或 `removed`，并与已有 `PSBIAS` 一致。没有明确头标记时，这仍是用户声明，不从亮度猜测。

`light` 后依次是绝对路径、SHA-256、偏置 ID、暗场 ID、平场 ID。ID 位置的 `-` 表示不使用该角色；SHA 位置的 `-` 表示首次预检绑定文件摘要。开始执行前，任务将全部来源替换为规范路径和实际摘要，并生成 UTC 日期等拍摄条件分组。每帧的母片选择保持独立；不会因为同组而跳过某帧温度检查。缺失分组字段不从文件名推断。

每批最多 4096 张亮场、256 张母片；清单最多 2 MiB。重复路径或内容、未使用母片、错位角色、冲突或不完整的关键拍摄信息都会拒绝。整批预检先于输出目录发布；之后仍逐帧检查像素与来源摘要，因此像素问题可使任务停在部分完成状态。

```sh
photonstack calibration-run --manifest /absolute/job-input.txt --output-dir /absolute/new-job
photonstack calibration-job-inspect --job /absolute/new-job
photonstack calibration-resume --job /absolute/new-job
```

`--max-frames N` 可用于首次运行和恢复，限制本次新计算的帧数；返回报告中的 `status: partial` 与 `completed/total` 明确表示剩余工作。已有完成帧不占这个额度。CLI 默认 stdout 只输出结果 JSON；设置 `PHOTONSTACK_PROGRESS=1` 后另外输出预检、校准与核验进度行，App 处理服务会将其分离成进度事件。

## 像素公式与缺失值

未处理亮场必须有偏置或暗场来处理偏置底座，不能只指定平场。令亮场为 L，偏置母片为 B，暗场为 D：

- 没有暗场：先计算 `L − B`。
- 暗场含偏置：计算 `L − D`，不再从亮场减 B。
- 暗场已去偏置：计算 `L − D − B`，必须提供 B。

平场已去偏置时直接使用；仍含偏置时先减 B，此时 B 还必须匹配平场本身的温度和拍摄条件。已经归一化却声明仍含偏置的平场被拒绝；偏置和暗场不允许携带非 `none` 的归一化标记。无论是否使用 B 校正平场，亮场都遵循上面的独立扣除规则。含偏置暗场避免重复减偏置的基本顺序也见 [Siril 手工预处理说明](https://siril.org/tutorials/tuto-manual/)。

校正后的平场按四个 CFA 存储相位分别求有限正样本的均值；显式单色求全平面均值。亮场除以 `平场 / 对应相位均值`。报告保留这四个均值、是否向亮场/平场减偏置、是否应用暗场/平场。

整数 FITS 的物理缩放和 `BLANK`、浮点 NaN/Inf 按传感器读取规则处理。缺失值传播；平场相对响应不大于 `1e-6` 时输出缺失，以避免极低响应导致任意放大。负的有限亮场结果保留，不裁剪为零；有限结果超过 Float32 范围时整帧失败。全部像素无效也不发布该帧。这里没有自动暗场曝光缩放、饱和检测、坏像素修补或暗场优化。

## 科学产物与恢复

任务根目录保存不可变的 `job.txt` 和 `job.sha256`，以及用于进程互斥的 `.lock`。每张完成帧使用一个独立目录：

| 文件 | 内容 |
| --- | --- |
| `frame-000001/calibrated.fits` | Float32 线性单平面，保持原始 CFA / 单色网格和负值 |
| `frame-000001/valid.fits` | 同尺寸的 1/0 有效性掩膜，不是插值结果或有效帧计数；此诊断图不带 WCS |
| `frame-000001/report.json` | 相位均值、无效/负像素数、实际 CPU 线程、分块与工作内存估算、计算及写图耗时 |
| `frame-000001/receipt.txt` | 任务摘要、帧与组索引、原图摘要及上述三个产品的摘要 |

`calibrated.fits` 不移动或插值像素，保留来源的拍摄、传感器和 WCS/SIP 头。只替换物理存储类型/缩放，去掉失效的 BLANK、数据范围、校验和及旧堆栈计数，写入 `PSCALIB='sensor-v1'`、`PSBIAS='removed'`。已标记处理状态的亮场不能再次进入本校准器。扩展 HDU 不复制；只输出校准后的主图像。

每帧先在任务内独立暂存，写完全部产品和摘要后以独占改名发布。SIGINT/SIGTERM 取消会清理本次未发布的暂存帧，保留已完成帧。强制终止可能留下隐藏暂存目录；恢复忽略这些目录，从未完成帧重新计算，不在半张图中继续，也不会把隐藏暂存文件当成成功结果。

恢复前核对完整任务、全部输入及每张已完成产物；正确的完成帧不会重写。任何输入、配方或已完成产品变更都报错，不静默覆盖。运行和检查遵守同一文件锁。目录已存在时首次运行拒绝；应明确使用恢复命令。App 处理服务同样保留取消/失败的任务目录，避免通用输出事务清理掉可恢复结果。

`calibration-job-inspect` 可以在原图移动后检查已保存产品，明确返回 `sourcesVerified: false`。它不意味着当前源文件仍与任务相同。恢复必须仍能读取记录的原路径；本阶段尚未提供来源重定位。报告包含每帧母片 ID、完整母片来源表、产品摘要、完成数及分组索引，未计算帧的产品表为空。

## 资源与验证边界

逐帧顺序执行，每帧内部按块并行；输出只保留当前帧的科学图和掩膜两个全尺寸平面，母片及亮场使用分块读取。默认像素工作预算 512 MiB，范围 4–8192 MiB；线程 1–32；分块 1–1048576 像素。报告中的 `workingBytes` 是像素工作区估算，不等于进程 RSS，亦不包含系统页缓存。后端明确为 CPU；不宣称 GPU 加速。

`calibrateAndWriteSeconds` 包含该帧来源核验、像素校准和两个 FITS 的写入，截止产品摘要计算之前。完整任务的墙钟时间还包括整批预检、最终来源/产品复核及记录写入。

测试覆盖显式逐帧选择、两夜/混合曝光分组、错误滤镜和平场偏置温度、含/不含偏置等价路径、CFA 相位与单色、负值与缺失掩膜、溢出、非法资源参数、重复校准拒绝、产物/输入篡改、目录和文件锁、真实进程取消后恢复。NumPy/Astropy 独立核对 4 张 2160×3840 模拟亮场的全部像素与 WCS，最大像素差为零；不同线程和分块的科学 FITS 与掩膜逐字节相同。

该模拟批次单次测量：一线程 3.888 秒，四线程 3.843 秒，四线程更大分块 3.831 秒，峰值 RSS 为 77.4–79.0 MB。数据已在页缓存附近，不能作为冷盘或真实相机质量基准，也不能据这个小差异宣称明显并行加速。可运行 `tools/scripts/qa/calibration_job_validation.py` 重现。真实校准素材验证、质量拒绝和坏像素图、人工元数据侧车、App 分配/执行/恢复界面及后续堆栈衔接仍待完成。
