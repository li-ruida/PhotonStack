# 单色母片强度匹配

入口：后期调整 → 高级 → 多滤镜合色与表达式 → 母片强度匹配（可选）。先完成[母片配准](master-registration.md)，再选择参考与待匹配母片。一次处理一张，可依次处理其他滤镜。输出为 `gain × target + offset`，不改变参考母片、像素坐标或 PSF。

“匹配并载入这张母片”另存结果并替换当前合色列表中的目标路径，保留其他母片及三条表达式。打开已保存结果只供复核；“载入这两张母片，重建 R / G / B 映射”会明确重建参考、目标两张母片，起点为 R=参考、G=B=目标。可再改用其他表达式。“按保存的参数重跑”复用增益与偏移，不重新拟合。

这种统计归一化适用于同一天区的近似线性强度关系。不同滤镜的发射线、恒星颜色、曝光、背景和 PSF 会改变关系，因此它是可选调色工具，不是 SPCC、滤镜响应标定、绝对测光或曝光时间推断。显著的残差可能来自真实天体结构，不应一概视为需消除的误差。[Siril 的线性匹配说明](https://siril.readthedocs.io/en/latest/processing/lmatch.html)也以已对齐图像的像素关系为前提；本实现使用下述稳健估计，不宣称与其最小二乘结果一致。

## 估计与复核

- 输入为相同尺寸的已配准线性单色 FITS，拒绝 CFA、RGB 和非线性编码。显式确认已配准；两张都有 WCS 时检查 9×9 网格，偏差超过 0.05 像素拒绝。无 WCS 时确认依赖用户，不能仅凭尺寸验证几何对齐。
- 最多 256×256 个空间均匀分块，每块使用确定性抖动位置取一个共同有限样本。每张图以共同样本分位剔除两端极值，默认 0.02–0.98；参数范围 0–1，跨度至少 0.1。它不依赖假设的 ADU 上限，也不能代替相机饱和阈值或坏像素标记。
- 画布再分成 8×8 棋盘格，交替用于拟合与留出检查。两组各需至少 64 个样本，并分别覆盖 4×4 区域中的至少 8 区。分位范围由共同候选样本确定，留出像素不参与增益/偏移拟合；这不是独立曝光或完全隔离的测试集。
- Double 坐标中心化/尺度归一化后进行 Tukey bisquare 迭代重加权，调节常数 4.685，尺度为残差 MAD×1.4826。最多 100 次，归一化系数变化小于 1e-10 才接受。初值来自两张图的中位数与 10–90 分位跨度。每次要求至少 64 个等效权重样本；动态范围不足、退化、未收敛、增益非正或非有限时拒绝输出。强度拟合是条件回归，未建模两轴的异方差测量噪声；不能将参数视为无偏物理响应估计。
- 报告列出拟合/留出数量、最终权重小于 0.5 的拟合样本数量、留出 RMS 前后值、带符号残差中位、绝对残差 P95，以及 4×4 各区的均值和 RMS。统计残差为 Double 预测减参考；保存的差图以最终 Float32 输出减参考，二者可有最后一次舍入差异。降低稳健拟合误差不保证未裁剪 RMS 或每个区域改善。
- 输出匹配后的母片、有效范围、差图；可以与原母片切换。界面在留出 RMS 变大或超过参考分位跨度的 10% 时提示复核，这是显示提示，不是科学准确性判据。差图使用现有 FITS 自动拉伸预览，不以颜色或中灰固定标记数值零点，应结合有符号统计读图。

`matched.fits` 保留所有目标有限像素，**不因参考局部缺失而删除目标信号**；Float32 溢出和无效目标仍为 NaN，不截断负数或 0–1 范围。`validity.fits` 为相应 0/1，不是曝光权重。`residual.fits` 为匹配后减参考，仅共同有限且差值可表示处有效。直接保留目标母片原有 TAN/SIP 坐标；不会把参考坐标复制给无解算目标。

## 命令行与保存

```sh
photonstack channel-match --aligned \
  --reference Ha=/data/registered/Ha.fits \
  --input OIII=/data/registered/OIII.fits \
  --low 0.02 --high 0.98 --output-dir /data/intensity-matched
photonstack channel-match-inspect --recipe /data/intensity-matched/recipe.txt
photonstack channel-match-replay --recipe /data/intensity-matched/recipe.txt \
  --output-dir /data/intensity-replayed
```

新目录不能已存在。`PhotonStack-Linear-Match-1` 配方保存两个来源的名称、路径、SHA-256、采样分位、实际增益/偏移、测量结果及三个产品的摘要。检查/打开校验来源和产品，重跑校验来源；写出前后复核来源，不能悄悄使用已改变的原片。App 从已打开的合色配方继续匹配前，也先核验该配方的来源。重跑重算诊断、保留原拟合降权数量，科学输出可逐字节比较。

CPU 拟合样本最多 65536，逐像素应用使用最多 8 个逻辑分段；不宣称 GPU 加速或始终同时运行 8 线程。保留两张输入和三张输出，工作内存随画布大小线性增长。独立注入、实际素材、App 交互与耗时记录见[验收记录](advanced-imaging-validation.zh-CN.md)。
