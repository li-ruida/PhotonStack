# 多滤镜母片配准

入口：后期调整 → 高级 → 多滤镜合色与表达式 → 母片配准与复核。

先为变量选择单色线性 FITS 母片，展开配准区域，选择方式和参考母片，再点“配准并载入母片”。新结果保持参考母片的画布与像素坐标，成功后自动加载到合色输入，并确认同网格；已有表达式不变。输入校准、背景、曝光倍率和通带响应不会在配准时自动修改。

- **共同星点**：估计平移、旋转与统一尺度。先作共同星点匹配，再用分布充分的局部 PSF 星心细化。至少 12 颗拟合星，细化 RMS 不超过 0.75 像素。重采样后另按网格选择共同星点检查，至少 12 颗、中位残差不超过 0.5、P95 不超过 1 像素。没有静默平移回退；缺少证据时提示失败。当前不是局部畸变、非刚性或星表盲解配准。
- **天球坐标 WCS**：要求每张母片都已带有支持的 ICRS TAN/TAN-SIP 解算，按参考画布作反向重投影。共同星点足够时使用相同的重采样后残差限值；不足 12 颗时保留坐标放置，但明确标为未通过共同星点复核。错误坐标在没有可用恒星时无法自动证明，不能把有 WCS 当成解算可靠。

报告里的后验星点可能与拟合星重复，不是保留的独立验证样本。重投影前后的像素网格、SIP 畸变和参考像素会一并处理；全部结果写入参考母片的 WCS。星点模式只有参考母片有可用 WCS 时才写入坐标，没有时不编造解算。

## 重采样与有效范围

原始母片不变。每张结果使用参考的尺寸，不自动扩大画布；画布之外的信号不会出现在这组结果中。参考母片的像素值直接保留，其他母片用正权重双线性插值，坐标计算使用 Double。整数位置不使用零权重的邻居；缺少任何正权重邻域时保留 NaN，无效范围不填黑、不反射、不作部分邻域归一化。相同 WCS 直接按同坐标采样，避免 SIP 数值反演误差损失边缘。

输出的 `<变量>.fits` 是 Float32 单色线性母片，`<变量>-validity.fits` 为 0/1 有效范围，不是采用权重或曝光时间。保留负数，只有有效范围能参与后续合色。双线性插值会改变 PSF 和噪声相关性；不同像素尺度之间按表面亮度式采样，不施加像素面积的 Jacobian 通量修正。需要测光或通带响应标定时应另行校准，不能把星点位置对齐当成通量标定。

“上次配准结果”显示每张母片的有效比例、共同星点数和残差，可查看单张结果及有效范围。“打开已配准母片”恢复输入；“按保存的变换重跑”在新目录重建结果。新目录不能已存在，取消或失败不会替换旧结果。

## 配方与命令行

```sh
photonstack channel-register --mode stars --reference Ha \
  --input Ha=/data/Ha.fits --input OIII=/data/OIII.fits \
  --output-dir /data/registered

photonstack channel-registration-inspect --recipe /data/registered/recipe.txt
photonstack channel-registration-replay --recipe /data/registered/recipe.txt \
  --output-dir /data/repeated

photonstack channel-compose --aligned \
  --input Ha=/data/registered/Ha.fits --input OIII=/data/registered/OIII.fits \
  --red Ha --green OIII --blue OIII --output-dir /data/hoo
```

`--mode wcs` 使用已有解算。配方保存原始路径、SHA-256、参考变量、方式、星点模式的测量变换、质量统计和输出摘要。查看/重开验证来源与结果；重跑验证来源，并复用已经保存的星点变换，WCS 模式从摘要已验证的原始头重建映射，不重新估计星点变换。配准目录和后续合色目录应一起保留：合色配方指向已配准母片，配准配方记录它们的原始来源。

当前为 CPU 执行，逐张读取移动母片，复用内存中的参考母片；插值按行分段并行，最多 8 个分段，不代表一直有 8 个活跃线程。真实数据和独立坐标/像素检查见[验收记录](advanced-imaging-validation.zh-CN.md)。

配准只处理几何。需要改变母片的增益与背景偏移时，另用[可选强度匹配](linear-intensity-match.md)，检查分区残差后再合色。
