# 融合结果自动检查

接缝报告保留曝光匹配前后的面板差值，并增加 `pairs[].final`：在真正融合完成之后测量输出，与相同网格的两块校正后面板比较。诊断只读取结果，不改变曝光匹配或混合像素。

每对天区共同覆盖范围最多采样 48×48 点，中心及四邻居覆盖须达到 99%。比较内容包括实际成片的中心亮度、两个方向梯度和中心减邻域均值的高通结构，计算其超出两输入包络的幅度。

- 背景候选：输入亮度在较低 40%、结构强度在较低 50% 的交集。这不是已确认的无星云背景；满幅弥散星云不能仅由亮度判断。
- 结构样本：较高 25% 的梯度或高通强度，用于检查细丝、星点和光晕变化。不会先以 3×3 中值抹掉细丝再检查。
- 阈值：相对数值舍入容差与背景候选中两面板高通差异的稳健尺度。不具有已标定的误报概率。
- `review`：发现超差，需放大查看；`insufficient-samples`：覆盖或背景候选不足；`no-large-excess`：仅表示采样范围未发现明显超差。

采样不是逐像素检查，不覆盖所有拼接外边缘。多于两块面板贡献同一点时，两输入包络可能低估合理范围。低分位背景候选也可能包含目标，因此报告不能证明“无接缝”或“星云细丝完全保真”。旧项目缺少 final 字段时保留旧报告，不伪造新检查。

独立数值测试包含原样输出、负背景、细丝被削弱、新增台阶与光晕、覆盖不足；三种混合方式开启/关闭诊断的 FITS 字节一致。真实面纱的全图最终接缝及细丝保护验收继续待补。
