# 拼接重叠区亮度检查

在天区拼接的预览或成片生成后，从质量报告打开“重叠区亮度检查”。它比较同一片天空在不同面板中的亮度，显示曝光匹配前后的变化。报告来自真正用于融合的几何配准和校正参数，支持星点、手动及 WCS 配准，也支持三种融合模式。

## 读数与操作

- 选择一对面板和 R/G/B 通道。左右两张 4×4 分区图分别显示匹配前后，同一通道共用色阶。红色表示第二块比第一块亮，蓝色表示更暗；灰色表示没有有效样本。分区均分重叠包围框，图中格子不是最终成片的接缝路径。
- 点击格子查看局部统计，或选择“查看整个重叠区”。面板编号与素材列表顺序一致；展开“实际应用的曝光校正”可核对输入文件路径、各通道 gain 和 offset。
- 中值差衡量整体偏移，RMS、绝对差 P95 和分区图能揭示中值接近零时仍存在的局部差异。某通道 RMS 增加超过 1% 会给出提示；这不是自动画质判定。小于 16 个有效样本时提示样本较少。
- “面板中值”列出同一组位置在两块面板中的局部亮度。它不保证采到纯背景：满幅星云、亮星和噪声仍可影响统计。
- 预览报告明确标为“预览采样”。它使用预览计算时的画布及输入分辨率；生成成片后使用成片报告。两种分辨率的样本位置、插值及曝光校正可能不同，不应混为一组统计。
- “导出报告”保存 JSON，包含输入路径、测量画布、曝光校正、整区及分区的所有数值。报告也随项目的拼接操作保存，可重开查看；旧项目没有报告时不会补造零差异数据。

测量单位沿用解码后输入数值，报告标记 linear / srgb / unknown。线性 FITS 的原始计数不会为了报告被归一化。诊断只读，不修改科学像素；曝光匹配本身仍按现有算法执行。

## 采样定义

每对相交面板在重叠包围框上最多放置 48×48 个网格中心；每个中心取共同画布上 3×3 个位置，分别逆投影到两个面板，并用与融合相同的覆盖率加权双线性插值读取颜色。所有九个位置在两块面板上的覆盖率均须至少 0.99，否则整个采样被排除。每块面板独立取九个数值的中值，再计算“第二块 − 第一块”。不做亮星裁剪或自动背景识别。

各统计量的定义：

- `firstMedian` / `secondMedian`：各面板局部中值的中值。
- `medianDifference`：逐样本差的中值；与“两面板中值之差”不必相等。
- `rmsDifference`：差值平方均值的平方根。
- `p95Absolute`：按绝对差排序，取 `ceil(0.95 × n)` 对应项（从 1 计数）。
- `madDifference`：差值偏离其中值的绝对偏差中值，不乘尺度系数。

偶数个数值的中值取排序后上中位数。没有有效样本时，统计量为 `null`，并保留候选数量。`bounds` 为测量画布像素边界 `[left, top, right-exclusive, bottom-exclusive]`；不是 FITS 的一基参考像素坐标，也不是最终缩略图上的坐标。

“匹配后”指对两块面板应用实际 gain / offset 后、融合前的差异。该报告不直接测量多频段融合后的最终过渡，也不能证明目标结构或绝对测光得到保留。请结合成片查看接缝、亮星、星云细丝和星系外围。

## CLI 与复验

~~~sh
photonstack mosaic --alignment wcs --blend feather --exposure-match on \
  --seam-diagnostics on --output veil.fits east.fits west.fits > report.json
~~~

默认开启；设为 `off` 仅关闭诊断。完成消息的 `seams` 字段包含报告。关闭诊断或旧版处理程序没有测量时，不显示可用诊断。独立合成测试比较全部统计字段，覆盖曝光匹配开关、三种融合方式、遮罩、薄重叠、无重叠、多面板以及全局偏移小但局部渐变显著的情况，并确认诊断开关不改变输出 FITS 的字节。

~~~sh
ctest --test-dir build/release -R photonstack_mosaic_seams --output-on-failure
python tools/scripts/qa/mosaic_seam_validation.py report.json veil.fits east.fits west.fits
~~~

后一个脚本使用独立的 NumPy、Astropy/WCSLIB，从原始面板重新投影并统计；需要安装对应 Python 包。它支持全分辨率线性 WCS 报告，不把本程序生成的模型像素当作真值。
