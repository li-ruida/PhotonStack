## 已处理的开销

- GPU：像素存储按 VM 页分配、CPU/GPU 借用同一内存；Winsor 中心值与归约一次命令提交；融合输出有限值验证；二维 stencil dispatch；闲置缓存延迟释放。Sigma median/MAD 独立噪声使用 GPU 计算首轮中心值，CPU 保持方差与分组累加顺序。校准复用不可变主帧校验和归一化均值，避免重复扫描及额外输出分配。
- 流水线：解码缓存按预算有界复用，未配准批次复用测量结果；配准缓存写入 worker；平均、最小、最大路径按选中帧流式读取；sensor pattern 应用并行化；同一次运行用文件版本校验代替重复 SHA，跨运行复用仍保留摘要与文件身份检查；sensor calibration session 复用已读主帧和均值。
- CPU：复用线程池和分位数 scratch；放宽硬编码核心/内存上限并保留内存准入；移除被覆盖的归一化统计、无用拉伸分支；独立 tile/row 并行；反卷积跨迭代复用大缓冲；质量统计减少全排序；多通道采样共享几何与覆盖计算；闪烁轨迹用一次构建的空间网格裁剪走廊候选，并恢复原索引顺序后执行原判断，密集情况保留全扫描回退。
- 编解码：复用 Core Image context；FITS 显示解码避免二次文件采样，常见 BITPIX 转换按块处理；RAW 后处理合并，ImageIO 像素转换并行，直接提供内存数据减少临时文件往返。
- 内存与拼接：提前释放去马赛克临时平面；云/拖影仅检测时可不复制原图；拼接普通预览先读头，再逐张解码缩小，RAW/旋转不确定尺寸保留可靠回退，WCS 保留原坐标路径；柱面三角函数按列复用；高斯金字塔每 worker 只保留五行；流星局部背景使用带 halo 的 256×256 分块积分表，避免整幅积分表；积分相减在极端 HDR 或稀薄覆盖下不稳定时回退原逐行求和。
- 交互：曲线输出内存 CGImage 并隔离高频发布；缓存锁不包含解码/缩放；图层和候选标记在后台串行渲染，合并连续修改并拒绝陈旧结果；裁剪告警先有限尺寸预览，停止修改后精算；预览缓存按内存配置，按视口解码；拼接报告缓存解析；大最终 JSON 跳过 progress 解析；裁剪缓存键包括位置。

## 范围说明

优化清单中的建议不是都适合直接替换生产算法。当前保留以下有意的边界：

- Metal shader 仍运行时编译一次并复用 pipeline；未引入额外 metallib 打包依赖。
- 独立噪声使用 CPU/GPU 混合路径，非完整 GPU 方差归约；Winsor 未盲目改成全 RGB 转置布局。
- 普通显示/编辑仍以 RGBA 为接口；sensor 单通道路径和临时平面优化并不等于全仓迁移为 Gray。
- 未用近似 LUT 替代 sRGB 舍入、未改用可能改变运算顺序的通用 BLAS/LAPACK 替换所有数值算法。
- UI 高频预览状态已隔离，未整体重写整个工作区 ObservableObject；保留精确结果生成和缓存完整性验证。
- 未取得用户真实大批次照片的完整 Instruments/峰值 RSS 对照；不会声称“所有性能问题已根除”。
