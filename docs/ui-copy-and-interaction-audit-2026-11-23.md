## 文案

- 简化导入、校准、后期、拼接检查及高级工具的名称和说明。例如“多滤镜合色与表达式”改为“通道合色”，“质量决定”改为“是否使用”，“保留科学值”改为“保留原始数值”。

- 23 处错误展示使用简短摘要，必要时可展开、复制原始报错。未知错误保留详情，不猜测原因。

## 修复

1. **XISF 转换按钮错误禁用**：无效的导入图像序号不再阻止导出；切换方向会重置序号。界面与模型共用参数校验，并限制文件选择类型。
2. **测光缺少禁用原因**：显示当前缺少的照片、星点、对齐确认或参数。区域重叠在启动前检查，与原生引擎采用相同间距条件。滤镜长度按 UTF-8 字节校验，避免中文名称在界面通过、引擎拒绝。
3. **测光加载无法取消**：读取序列、重新打开结果的任务有取消入口；关闭窗口会取消加载。正常取消不显示为错误。
4. **测光参数名称错误**：背景“内径 / 外径”改为“内半径 / 外半径”。修改设置后，已保存的旧结果入口标为“上次结果”。
5. **插件输入状态不一致**：检查配置或处理期间禁止更换源图，配置检查也阻止重复进入。
6. **错误 JSON 解析脆弱**：允许诊断前后存在日志，正确处理 JSON 字符串内的花括号与转义，不把进度消息当成错误。天区拼接错误仍可定位到对应分区。
7. **GHS 参数反馈**：参数无效时说明保护点顺序及黑白点条件。
