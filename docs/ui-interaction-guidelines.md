# 工具交互约定

主要工作流保留顶部步骤导航；工具弹窗按下面的规则组织，避免同一操作在不同工具里有不同含义。

- **关闭**：位于编辑工具右上角，空闲时可用 Esc 关闭。任务运行时先通过“取消任务”停止；保存期间禁止关闭。
- **取消任务**：位于底部状态区，停止当前处理并保留工具窗口。支持 ⌘.。不可取消的保存操作只显示保存进度。
- **保存 / 使用结果**：位于底部右侧，使用唯一的突出按钮。支持 ⌘Return；普通 Return 保留给参数输入。
- **预览 / 更新预览 / 重置**：位于参数区，使用普通按钮。修改参数后，旧预览仍可查看，但必须更新后才能保存。
- **导入与配置弹窗**：取消和主操作相邻，放在底部右侧；“取消”退出当前配置，不启动处理。
- **运行状态**：进度在底部左侧，错误在操作栏上方。运行时禁止更换输入、修改处理参数或重复提交。
- **错误**：简短说明原因，原始错误可展开查看和复制。
- **按钮文字**：用“动作 + 对象”，如“开始校准”“导出标注”。还需选择文件、位置或填写内容时加省略号；立即执行的动作不加。
- **术语**：处理配置称“参数”，可复用的处理步骤称“工作流”，质量复核称“检查”。打开完整结果目录时写“打开结果”，不写“打开参数”。
- **说明与输入提示**：中文界面使用中文提示，保留 FITS、PSF、Hα 等格式或专业名称。按钮写短，副本保存、通道重设、输入数量等限制写清楚。
- **添加与更新**：新增项目使用“添加”；覆盖同一字段的已有值使用“更新”。纯图标按钮提供中文帮助与辅助功能名称。

`ToolSheetControls.swift` 提供操作栏、关闭按钮、进度与取消入口、主操作样式和快捷键。当前用于 GHS、背景校正、星图定位、光谱校色、Gaia 星表、时间序列测光、SER / XISF 导入转换、校准母片检查和元数据修正。工作区导航、设置开关和其他专用工具不应为了套用组件而改变自身操作含义。
